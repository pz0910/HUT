摘要

Retouch Agent 正处于从"单步模型"到"多步智能体"的范式跃迁期。学术界 2025-2026 年 MLLM-Agent 路线论文爆发（30 篇中占 10+ 篇），RetouchIQ 和 Agent Banana 代表了两种核心范式：参数化调优 Agent（调 Lightroom 参数）和 原子工具调用 Agent（replace/remove/add 等操作）。商业市场则高度碎片化——19 款产品中仅 Photoshop AI 的 Generative Fill 触及"文字指令编辑"，其余仍是参数滑块或一键模板模式。核心差距：学术前沿的 Agent 自主规划+多轮迭代能力，商业产品几乎未落地。 未来 1-2 年，文字指令交互和个性化风格学习将是最先落地的两个方向。

RetouchIQ 核心洞察：

  • 通用奖励模型（GRM）能动态生成评估指标，解决了修图质量主观性问题
  • 参数化编辑（输出 {exposure=+0.9; contrast=-30}）比端到端生成更可控、可解释
  • 190K 指令-推理对的数据管线可复用

Agent Banana 核心洞察：

  • Planner-Executor 双层架构是 Agent 编辑的标准范式
  • Context Folding 三层记忆（Asset/Execution/Planning）解决了多轮交互的上下文溢出问题
  • Image Layer Decomposition（ILD）实现"定位→局部编辑→融合"，天然支持 4K+
  • PIED 现象（多轮编辑中非编辑区域向先验漂移）是重要警示

4. 趋势预判

4.1 未来 1-2 年技术趋势

确定性高的趋势（有明确信号）：

1. 文字指令将成为标配交互。 Photoshop Generative Fill 已验证需求，InstructPix2Pix 2000+ 引用证明技术成熟。预计 Luminar Neo、Capture One 等将在 1-2 年内跟进文字指令功能。

2. 个性化风格学习将普及。 Imagen AI 的"学习你的修图风格"模式已被婚礼/商业摄影师验证，Aftershoot 也在跟进。预计更多产品将支持上传历史作品训练个性化模型。

3. Diffusion 模型全面取代 GAN。 新产品（Magnific、Clipdrop）已转向 Diffusion，老产品（Let's Enhance）仍在用 GAN 但效果落后。GAN 在修图领域将退居辅助角色。

4. 单一功能 → 平台化。 Remove.bg 扩展 API 生态，Clipdrop 整合 7+ 工具。单一 AI 功能正被平台型产品吸收。

需要观察的趋势（信号尚弱）：

5. 端侧大模型驱动的 Agent 修图。 目前 RetouchIQ/Agent Banana 依赖云端 LLM（GPT-5-mini 等），成本高。若端侧 VLM（如 Phi-3-Vision、Qwen-VL 端侧版）成熟，Agent 修图的成本和延迟问题将大幅缓解。

6. 修图评估标准化。 目前缺乏统一的 retouch 质量评估标准（RetouchIQ 用 SC/PQ，Agent Banana 用 HDD-Bench）。行业可能需要 1-2 年建立共识。

5. 结论与建议

5.1 核心结论

1. 学术与商业存在 1-2 年代差。 学术界 2025-2026 年已进入 MLLM-Agent 时代（自主规划、多轮迭代、奖励模型），商业产品仍停留在参数滑块和一键模板阶段，仅 Photoshop 触及文字指令。

2. 两条技术路线值得关注： RetouchIQ 的"参数化 Agent"（调 Lightroom 参数）适合专业修图场景，Agent Banana 的"原子工具 Agent"（replace/remove 等）适合通用编辑场景。两者不互斥，可互补。

3. 商业市场碎片化严重。 19 款产品覆盖桌面/移动/在线/新兴四类，没有一款产品覆盖所有场景。垂直场景（降噪、抠图、放大）已被充分竞争，通用 Agent 修图是蓝海。

4. 个性化是已验证的付费点。 Imagen AI 的"学习你的风格"模式证明用户愿意为个性化付费。这是学术成果（PerTouch 个性化修图 Agent）最容易商业化的方向。

⭐1. RetouchIQ: MLLM Agents for Instruction-Based Image Retouching with Generalist Reward

  • 来源： arXiv preprint (cs.CV), 2026年2月
  • 作者： 一作 Qiucheng Wu (UC Santa Barbara / Adobe Research 实习)，通讯作者 Handong Zhao (Adobe Research)，机构 Adobe Research + UC Santa Barbara
  • 核心问题： 基于指令的图像修图中，创意编辑具有主观性，传统的基于规则的像素级奖励（如与固定参考图计算相似度）无法可靠地指导强化学习训练。需要一种能灵活评估编辑质量的通用奖励模型。
  • 核心方法：

整体框架： RetouchIQ 是一个 MLLM Agent 框架，将用户的自然语言指令转化为可执行的参数化编辑操作（如 {exposure=+0.9; contrast=-30}），在 Adobe Lightroom 中执行。采用两阶段训练：监督微调 (SFT) + 强化学习 (RL)。

通用奖励模型 (Generalist Reward Model, GRM)： 核心创新点。不同于传统固定指标的奖励，GRM 是一个经过 RL 微调的 MLLM，能根据具体场景动态生成评估指标，再给出标量奖励分数。例如，对于"营造秋日氛围"这类主观指令，GRM 会自主生成色调温暖度、色彩一致性等评价维度。

策略引导奖励训练 (Policy-Guided Reward Training, PGRT)： 发现用随机扰动生成的"弱编辑"训练奖励模型存在分布偏移问题。PGRT 策略让奖励模型在 RL 阶段使用策略模型实际生成的弱编辑进行训练，从而对齐奖励模型与策略模型的数据分布。

数据管线： 构建了 190K 指令-推理对的大规模数据集。从真实用户编辑轨迹出发，用 MLLM 标注编辑意图和推理过程。

  • 交互方式： 全自动（用户输入自然语言指令，Agent 自动完成全部编辑）
  • 实验结果： 自建 RetouchEval 基准（300对），与 GPT-5、Gemini-2.5、Flux-Pro、MonetGPT、JarvisArt 对比。RetouchIQ-GRM 在语义一致性(SC)和感知质量(PQ)上全面领先。MIT-Adobe5K 上 SSIM=0.86, LPIPS=0.16, PSNR=23.14。
  • 开源代码： 未开源。基于 Adobe Lightroom 平台，复现门槛较高。
  • 局限性： 依赖 Adobe Lightroom 作为执行平台；奖励模型上限有待验证；交替训练策略增加训练复杂度。
  • 与 retouch agent 关联： GRM 概念高度可借鉴——"动态生成评价指标+标量打分"的通用奖励范式；PGRT 的分布对齐思路；参数化编辑 vs 端到端生成的验证；数据标注管线可复用。

⭐2. Agent Banana: High-Fidelity Image Editing with Agentic Thinking and Tooling

  • 来源： arXiv preprint (cs.CV), 2026年2月

  • 核心方法：

层次化 Agent 框架： 采用 Planner-Executor 双层架构。Planner 负责全局意图理解和任务分解；Executor 负责原子级编辑操作的执行。Executor 内置自反思机制（Quality Test），编辑结果不达标时自动重试、回滚和重新规划。

Context Folding（上下文折叠）： 将交互历史分为三层：(1) Asset Level：将图像抽象为轻量语义节点；(2) Execution Level：单步推理的瞬时工作记忆，完成后被"折叠"；(3) Planning Level：经验证的有效编辑路径的持久记忆。使 Agent 在数十轮交互后仍能保持清晰的全局状态认知。

Image Layer Decomposition (ILD)： 采用"分解-编辑-融合"的局部处理范式。利用动态对象感知掩码精确定位目标区域，无损裁剪为独立图层块，冻结背景像素状态。编辑完成后用高斯混合算法无缝拼回原图。定义了五种原子操作：replace、remove、add、adjust、undo。

  • 交互方式： 全自动（多轮对话式，用户逐步提供指令，Agent 自动规划和执行）
  • 实验结果： HDD-Bench 上 IC=0.871, SSIM_OM=0.84, LPIPS_OM=0.12，多轮一致性和背景保真度最优。仅 Agent Banana 和 Nano Banana Pro 支持原生 4K 编辑。
  • 开源代码： 项目主页 agent-banana.github.io，底层使用 GPT-5-mini，复现成本较高。
  • 局限性： 依赖闭源模型，API 成本高；HDD-Bench 仅 96 个会话；ILD 的对象掩码生成质量直接影响编辑精度。
  • 与 retouch agent 关联： Planner-Executor 架构直接可参考；Context Folding 的三层记忆机制对多轮修图至关重要；ILD 局部编辑思路；五种原子操作为工具集设计提供参考模板；PIED 现象提醒关注非编辑区域保真度。

⭐3. PerTouch: VLM-Driven Agent for Personalized and Semantic Image Retouching

  • 作者： 一作 Zewei Chang，通讯作者 Chongyi Li，机构：南开大学 + Samsung R&D Institute China-Beijing
  • 核心问题： 现有图像修图方法存在三大不足：(1) 缺乏主观性建模，无法适应不同用户的个性化审美偏好；(2) 缺乏区域级精细控制；(3) 缺乏用户交互建模与个性化记忆机制。

语义感知区域修图架构： 以 Stable Diffusion 为骨干，通过 ControlNet 注入区域级属性参数图（4个通道：饱和度、对比度、色温、亮度）。使用 SAM 进行全景分割获取语义区域。

  • 交互方式： 半自动（支持自然语言指令，支持弱指令全自动和强指令精细化控制）
  • 实验结果： 在 MIT-Adobe FiveK 上评估，PSNR/LPIPS 达到或超越 SOTA。用户研究（50名志愿者）显示偏好选择率显著优于所有基线。
  • 开源代码： https://github.com/Auroral703/PerTouch，Star 23，刚开源不久。
  • 局限性： 依赖 SAM 分割质量；仅支持4个预定义属性；推理速度受限于扩散模型多步采样；场景记忆依赖足够的交互历史。
  • 与 retouch agent 关联： VLM驱动的Agent架构（区分强/弱指令）、反馈驱动反思机制、场景感知长期记忆机制。将自然语言指令转化为可控参数图的pipeline设计思路。

⭐4. InstantRetouch: Efficient and High-Fidelity Instruction-Guided Image Retouching with Bilateral Space

  • 来源： CVPR 2026
  • 作者： 一作 Jiarui Wu，通讯作者 Yujin Wang，机构：上海人工智能实验室 + 香港中文大学 MMLab + CPII under InnoHK
  • 核心问题： 基于扩散模型的指令引导图像修图面临两大问题：(1) 保真度不足——生成式模型会改变几何结构和纹理；(2) 效率低下——多步扩散采样计算代价高昂。

双边空间表示： 不直接编辑像素或潜在表示，而是预测一个低分辨率的3D双边网格，存储仿射变换参数。通过学习的引导图对双边网格进行切片，生成逐像素仿射系数并应用于全分辨率图像。这种表示天然与内容解耦——只编码光照/色彩变换参数，不包含图像内容信息，从根本上保证高保真度。4K分辨率下推理时间恒定约0.065秒。

单步双边蒸馏框架： 构建约20万组指令-修图三元组数据集。将变分分数蒸馏（VSD）引入双边网格框架：学生网络包含两个协同分支——低分辨率扩散分支负责语义理解，全分辨率双边处理分支负责高保真度输出。采用渐进式训练策略。

提示对齐损失： 基于CLIP的对比学习损失，提供语义监督以改善指令遵循能力。

iRetouch基准： 500组来自Adobe Lightroom社区的真实修图前后对比对。

  • 交互方式： 全自动（单步前向传播，支持连续强度调节——标量s控制仿射变换强度）
  • 实验结果： 720p到4K推理时间恒定约0.065秒，比大型编辑模型快70-900倍。SSIM、CW-SSIM等指标达到SOTA。综合得分8.54，与Gemini-2.5-Flash（8.74）高度竞争。用户研究在内容保真度、编辑能力、视觉质量和整体偏好四维度均获最高评分。
  • 开源代码： https://github.com/OpenImagingLab/InstantRetouch，Star 4（刚发布）。附带iRetouch基准数据集。
  • 局限性： 双边空间的仿射变换本质上是线性操作，对高度非线性的复杂色调映射表达能力有限；无法进行几何/内容级编辑；对极其精细的区域控制能力有待验证。
  • 与 retouch agent 关联： 双边空间表示——将修图从"生成新内容"转化为"预测变换参数"，从根本上解决保真度问题；VSD蒸馏将扩散先验压缩到单步推理中，适合Agent实时交互；连续强度调节机制可直接用于Agent让用户微调效果；iRetouch基准可作为评测参考。

⭐5. MonetGPT: Solving Puzzles Enhances MLLMs' Image Retouching Skills

  • 来源： ACM Transactions on Graphics (TOG), 2025, Vol.44 No.4
  • 作者： 一作 Niladri Shekhar Dutt (UCL)，通讯作者 Niloy J. Mitra (UCL + Adobe Research)，机构 University College London + Adobe Research UK
  • 核心问题： 现有 MLLM 直接用于图像修图时，缺乏对图像处理操作的内在理解——不知道每个操作做什么、调多少合适、如何规划多步编辑序列。
  • 核心方法：

视觉谜题训练范式（Visual Puzzles）： 设计三类视觉谜题：(1) Puzzle A（操作识别）——给定原图和编辑后图像的拼接对，让 MLLM 识别是哪个操作、调了多少值；(2) Puzzle B（美学判断）——给定专家编辑图及其4个扰动变体，让 MLLM 排序并识别最优图；(3) Puzzle C（规划生成）——给定原图和专家编辑图，让 MLLM 生成分阶段的完整编辑计划（光照→色温→颜色特调）。

推理数据集合成管线： 利用 PPR10K 数据集的专家编辑图，通过程序化扰动生成训练数据。用 Gemini 2.0 Flash 生成推理文本，"接地"防止幻觉。整个合成数据集约 25K 样本。

推理驱动回归（Reasoning as Pathway for Regression）： 推理阶段，MLLM 先生成编辑计划 P（包含推理文本），再基于计划 P 和原图回归精确的参数值 A。分三阶段顺序执行（光照→色温→颜色特调），每阶段执行后将编辑结果反馈给 MLLM。

  • 交互方式： 半自动（MLLM 自动生成编辑计划和参数，用户可在任意阶段查看、修改或覆盖计划）
  • 实验结果： Adobe5K 泛化测试：SSIM=0.90, LPIPS=0.07, PSNR=23.75。与 Google Photos 持平（0.90 vs 0.90），全面超越所有开源基线。RTX 4090 上完整三阶段 25 秒/张。
  • 开源代码： 项目主页 monetgpt.github.io，基于 Qwen-VL-7B 微调（DoRA adapter），使用 llamafactory 框架。声明提供代码、数据、模型。
  • 局限性： 仅支持全局操作，不支持区域编辑；训练数据仅 8K 专家编辑图，单一专家审美偏见；依赖 PPR10K 数据集（人像为主）。
  • 与 retouch agent 关联： 视觉谜题训练范式——"先教 Agent 理解工具，再教它使用工具"；推理驱动回归 > 直接回归；分阶段执行 + 反馈闭环；用户可覆盖计划的半自动交互模式；程序化操作库设计参考。

5. 关键结论

1. 从模型到 Agent 是不可逆趋势： 2025-2026 年的论文几乎都采用 LLM/VLM Agent 架构，而非单一端到端模型。Agent 的优势在于可解释性、可控性和可组合性。

2. 保真度是修图的底线： InstantRetouch 的双边空间思路（content-decoupled）和 Agent Banana 的 ILD 思路（局部编辑冻结背景）从不同角度解决了保真度问题，这是修图 Agent 必须优先保证的。

3. 个性化是差异化竞争力： PerTouch 的场景记忆和 RetouchIQ 的 GRM 都指向同一个方向——修图 Agent 需要理解"这个用户喜欢什么样的修图风格"。

4. 效率决定落地可行性： InstantRetouch 的 0.065 秒推理证明了实时修图的可行性，而 Agent 类方法的多轮推理延迟仍是瓶颈。

5. 数据仍是关键瓶颈： InstructPix2Pix 的自动数据生成管线、PPR10K 的专业标注、MonetGPT 的谜题合成，都在尝试用不同方式解决修图数据稀缺问题。

七、关键发现与趋势

1. 技术趋势

  • 2023-2024： Diffusion 模型主导（InstructPix2Pix, Prompt-to-Prompt, DragDiffusion）
  • 2025-2026： MLLM-Agent 快速崛起（RetouchIQ, Agent Banana, PerTouch, MIRA），成为新主流
  • 多 Agent 协作： 2026 年出现多个 Multi-Agent 框架（CAMEO, ImageEdit-R1, ScaleEdit-12M）

2. 修图 Agent 特点

  • 从"模型"到"Agent"： 早期用单一模型（GAN/CNN）直接修图，现在用 LLM/VLM Agent 自主规划+执行
  • 训练无关（Training-free）： RetouchLLM、MonetGPT 等利用 LLM 零样本能力，无需专门训练
  • 个性化： PerTouch、InstantRetouch (personalized) 关注用户个人修图偏好

3. 交互方式演进

  • 早期： 全自动（CNN 直接输出）→ 参数调节
  • 中期： 文字指令（InstructPix2Pix）→ 涂抹交互（MagicQuill）
  • 最新： Agent 自主规划（RetouchIQ）→ 多轮迭代（MIRA）

4. 数据与评估

  • 数据集： PPR10K（人像，80 引用）是主要基准，但缺乏通用修图数据集
  • 评估： 缺乏统一的 retouch 质量评估标准，多数论文使用 FID/LPIPS 等通用指标

六、技术趋势观察

1. 扩散模型正在取代GAN：Magnific、Clipdrop等新产品已转向Diffusion Model，早期产品（Let's Enhance）仍基于GAN

2. 个性化风格学习成标配：Imagen AI和Aftershoot支持学习摄影师个人风格，是专业工具核心差异化

3. 文字指令交互崛起：Photoshop Generative Fill是唯一支持文字指令的桌面工具，预计2026年更多产品跟进

4. 本地vs云端分化：专业用户倾向本地处理（Topaz、DxO），普通用户接受云端（Remove.bg、Fotor）

5. 单一功能→平台化：Remove.bg扩展到API生态，Clipdrop整合7+工具，单一AI功能正被平台取代

6. 按量付费回归：Imagen AI按张计费适合低频用户，与订阅制形成互补

7. 美颜AI两极分化：亚洲市场（美图秀秀）深度人像处理 vs 欧美市场（Lightroom）专业调色路线

阶段 1：学术调研（核心）

目标： 建立 retouch agent 领域的学术知识图谱

步骤内容产出
1.1 关键词矩阵构建搜索关键词组合关键词表
1.2 论文搜索arXiv / Google Scholar / 顶会论文搜索论文列表（30+ 篇）
1.3 初筛分类按技术路线、应用场景、交互方式三维度分类分类表
1.4 精读深挖选 5-10 篇代表性论文精读精读笔记
1.5 代码溯源找到对应开源代码仓库代码清单

关键词矩阵：

维度关键词
核心retouch agent, image retouching, photo editing AI
技术neural image enhancement, diffusion-based editing, GAN retouching, transformer image edit
应用portrait retouching, skin smoothing, background removal, color grading AI
交互instruction-based editing, text-guided retouching, interactive image editing
Agentmulti-step editing, automated editing pipeline, editing workflow agent

精读论文标准（选 5-10 篇）：

  • 发表在顶会/顶刊（CVPR, ICCV, ECCV, NeurIPS, ICML, SIGGRAPH, TOG）
  • 引用量较高或近 1 年高影响力新作
  • 有开源代码实现
  • 覆盖不同技术路线（至少 GAN / Diffusion / Transformer 各 1 篇）
  • 覆盖不同应用场景（人像 / 通用 / 风格化）

精读笔记模板：

## [论文标题]
- 来源：[会议/期刊, 年份]
- 作者：[一作, 通讯作者, 机构]
- 核心问题：[解决什么问题]
- 核心方法：[技术路线，关键创新点]
- 交互方式：[全自动 / 半自动 / 交互式]
- 实验结果：[关键指标，对比基线]
- 开源代码：[GitHub 链接，Star 数]
- 局限性：[作者承认或分析的不足]
- 与本项目关联：[可借鉴的技术点]
